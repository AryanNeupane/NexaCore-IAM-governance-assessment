# Organization Profile

## NexaCore Technologies

**NexaCore Technologies** is a fictional mid-sized SaaS company created specifically for this educational project.

The organization provides cloud-based technology services to business customers and maintains a typical SaaS environment containing corporate applications, development platforms, business systems, cloud infrastructure, and sensitive business information.

### Organization Size

Approximately **150 employees**, supported by a smaller population of contractors, privileged users, and service accounts.

### Departments

* Executive Leadership
* Engineering
* IT
* Finance
* HR
* Sales
* Customer Support

### Key Applications

| Application       | Primary Purpose                        |
| ----------------- | -------------------------------------- |
| Microsoft 365     | Collaboration, email, documents        |
| GitHub            | Source code and development            |
| Jira              | Development and project management     |
| Salesforce        | Customer and sales management          |
| HRIS              | Employee lifecycle information         |
| Finance Platform  | Financial operations                   |
| Cloud Environment | Infrastructure and application hosting |

### Identity Population

| Identity Type    | Approximate Population | Governance Consideration                 |
| ---------------- | ---------------------: | ---------------------------------------- |
| Employees        |                   ~130 | Standard Joiner-Mover-Leaver lifecycle   |
| Contractors      |                    ~10 | Time-bound access and expiration         |
| Privileged Users |                     ~8 | Stronger controls and periodic review    |
| Service Accounts |                     ~5 | Named ownership and lifecycle management |

> All populations and data in this project are fictional and created for educational purposes.
