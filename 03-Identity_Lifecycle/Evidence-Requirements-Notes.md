# NexaCore IAM Evidence Requirements

## Evidence Standard

Evidence should allow an assessor with no prior context to reconstruct:

- What happened
- Who authorized it
- When it happened
- What access was granted or removed
- Whether the resulting access was appropriate

This evidence standard applies consistently across the entire identity lifecycle.

## Joiner Evidence

- HR onboarding record
- Access request
- Approval
- Provisioning record
- User/account record

## Mover Evidence

- HR role-change record
- Previous access
- Updated access
- Approval
- Access removal/provisioning evidence

## Leaver Evidence

- Termination record
- Deprovisioning record
- Application access status
- Privileged access removal evidence

## Contractor Evidence

- Contract/sponsor record
- Access approval
- Defined expiration date
- Access review record

## Evidence Assessment Standard

For each JML event, the available evidence should demonstrate:

| Evidence Question | What the Assessor Should Be Able to Determine |
|---|---|
| What happened? | The identity lifecycle event and access change |
| Who authorized it? | The responsible approver(s) |
| When did it happen? | Relevant request, approval, provisioning, or removal dates |
| What changed? | Access granted, modified, or removed |
| Was it appropriate? | Alignment with the user's role and business need |


**Assessment principle:** Evidence should be sufficient for an independent reviewer to understand and validate the access decision without relying on undocumented assumptions or verbal explanations.
